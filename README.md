# Каким будет урожай? 

Сайт, который простыми словами показывает, каким получится урожай в этом году по сравнению с обычными годами и почему. Есть калькулятор урожая для своего огорода.

Сейчас на сайте прогноз урожайности **пшеницы в Казахстане** по погоде сезона и урожаям 2000–2025 годов.

## Что на сайте

- **Главный вывод** для всех: «немного хуже обычного», «10 мешков → 9», риск неурожая «8 из 10», погода лета, совет для огорода.
- **Калькулятор огорода**: 12 культур, грядка или теплица, погода лета и полив, итог в килограммах.
- **График** урожая по годам и прогноз.
- **Для специалистов**: сравнение методов (среднее, тренд, гребневая регрессия, байесовская регрессия), проверка по годам, вероятности.
- **Свои данные**: можно ввести урожай и погоду по годам или загрузить CSV.

## Файлы

| Файл | Что это |
|---|---|
| `yield-forecast.html` | Исходник сайта (вся логика внутри, без библиотек) |
| `index.html` | Версия для GitHub Pages, собирается из исходника |
| `collector/collect.mjs` | Сборщик данных: FAOSTAT, NASA POWER, ERA5 |
| `collector/build-site.mjs` | Сборка `index.html` |
| `data/kz_wheat.csv` | Готовая таблица: год, урожайность, осадки, жара |
| `data/manual_yields.csv` | Урожайность за годы, которых ещё нет в FAOSTAT |
| `DESIGN.md` | Описание дизайна |

## Как обновить данные

Нужен [Node.js](https://nodejs.org/) 18 или новее.

```bash
node collector/collect.mjs
node collector/build-site.mjs
```

Первая команда скачивает данные и пересобирает `data/kz_wheat.csv`. Вторая собирает `index.html`.

Погода из ERA5 (точнее, чем NASA POWER) требует бесплатного ключа Copernicus CDS и принятой лицензии набора ERA5 time-series:

```bash
CDSAPI_KEY=ваш-ключ node collector/collect.mjs --weather era5
```

В PowerShell: `$env:CDSAPI_KEY="ваш-ключ"; node collector/collect.mjs --weather era5`. Не сохраняйте ключ в файлах репозитория.

Когда появится официальная урожайность нового года, добавьте строку в `data/manual_yields.csv`. Как только год появится в FAOSTAT, сборщик возьмёт его оттуда.

## Как опубликовать на GitHub Pages

1. Сделайте репозиторий публичным (на бесплатном плане Pages работает только для публичных).
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<имя>.github.io/<репозиторий>/`.

После изменений в `yield-forecast.html` не забудьте пересобрать `index.html`.

## Источники данных

- Урожайность 2000–2024: [FAOSTAT](https://www.fao.org/faostat/), набор Production: Crops and livestock products (FAO ООН).
- Урожайность 2025: предварительные итоги Бюро национальной статистики Республики Казахстан.
- Погода: [NASA POWER](https://power.larc.nasa.gov/) (NASA Langley Research Center), среднее по трём точкам зернового пояса: Костанайская, Северо-Казахстанская, Акмолинская области.
- По желанию: [ERA5](https://cds.climate.copernicus.eu/) (Copernicus Climate Change Service, лицензия CC-BY).

## Ограничения

- Прогноз — оценка по погоде и прошлым урожаям, а не официальная статистика.
- Погода берётся по трём точкам, а урожай — по стране в целом, поэтому прогноз приблизительный.
- Калькулятор огорода использует средние справочные урожаи и простые поправки на погоду. Это ориентир, он не проверялся на реальных урожаях огородов.
